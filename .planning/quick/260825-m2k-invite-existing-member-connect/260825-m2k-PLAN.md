<objective>
When an artist invites a collaborator, decide BEFORE sending whether that email already
belongs to a Funūn account. If it does, send a collaborator connection request through the
existing connections machinery instead of a "join Funūn" signup invite; accepting it links
that member to the inviter's roster row. If it does not, nothing changes.

Purpose: the owner (and every artist) currently gets a wasted invite — the mismatch is only
discovered after the recipient clicks, on a signup page that offers no way to accept the
collaborator relationship. The invite dead-ends.

Output: one small service-role RPC, two extracted lib helpers (connection-request core,
scoped claim), a membership branch in the shared invite helper, and outcome-aware invite UI
that also stops lying about failed email sends.
</objective>
