# Distributor API Partner Options

## Objective

Preserve the researched distributor and distribution-infrastructure integration options
as a durable decision plan for later owner, team and Claude/GSD review.

## Scope

- Record Too Lost as the fastest public-API pilot candidate.
- Record Revelator as the strongest API-first strategic comparison.
- Record FUGA as an enterprise destination and SonoSuite as a scale-dependent
  white-label alternative.
- Record DistroKid, TuneCore, CD Baby, Spotify, Apple Music and Secretly as
  business-development or named-partner discovery paths rather than assumed public APIs.
- Define evaluation criteria, outreach questions, technical stages, truthful claim gates
  and a reversible selection process.
- Keep all partner contact, account creation and commercial commitments owner-controlled.

## Validation Plan

- Confirm every researched option appears with its correct maturity and limitations.
- Confirm the plan distinguishes public API availability from commercial permission,
  sandbox acceptance and production delivery.
- Confirm no option is represented as selected, contracted or integrated.
- Confirm manual package export remains the fallback until a partner accepts delivery.
- Run `git diff --check` on every changed planning file.

## Risks / Coordination Notes

- Vendor capabilities, pricing, eligibility and API terms can change; refresh the research
  before outreach or selection.
- Public documentation does not itself authorize commercial production distribution.
- The Song Passport, Release Report, Sound Vault custody controls and DDEX readiness work
  must remain provider-neutral until a named partner passes sandbox UAT.
- No external outreach, developer-account creation or commercial commitment is authorized
  by this planning task.
- Existing unrelated worktree changes belong to the user and will not be modified.
