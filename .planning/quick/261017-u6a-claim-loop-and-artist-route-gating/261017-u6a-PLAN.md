<objective>
Two fixes on branch fix/audit-2026-10, one commit each.

A) GitHub #191. Middleware fires POST /api/claim-collaborators on every navigation while
user_profiles.claimed_at IS NULL. For a confirmed user whose auth metadata carries no usable
signup_invite_token, complete_verified_signup_claim returns FALSE before it ever writes
claimed_at (214:201-205), so the sentinel never flips and the loop runs forever. Add an
additive migration 244 that sets claimed_at on that verified, no-token path only.

B) Middleware isProtected is an allowlist that misses 14 app/(artist) routes. Extract the
predicate into a pure module, extend it to cover every artist route by default, keep the
intentionally public pages reachable, and test it.

Purpose: stop a per-request RPC + auth round trip for affected users; require sign-in on all
artist routes as defense in depth.
Output: migration 244 (authored, committed, NOT applied), protectedRoutes module, tests.
</objective>
