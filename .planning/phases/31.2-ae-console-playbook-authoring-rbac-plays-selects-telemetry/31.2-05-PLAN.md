| Boundary | Description |
|----------|-------------|
| public /selects/[token] viewer → engagement POST | An anonymous/cookie-attributed caller writes telemetry rows leadership will act on |
| client-computed delta → server persist | The server, not the client, is the source of truth for the accepted delta bound |
| telemetry data → the public client render | Engagement must never be readable on the client-facing player (staff-only) |
