**Analog:** `lib/admin/gate.ts`

**Core auth-gate pattern** (gate.ts lines 34-52, `requireStaff`):
```typescript
export async function requireStaff(
  allowed: StaffRole[] = OPERATIONAL_STAFF_ROLES
): Promise<RequireStaffResult> {
  const supabase = await createApiClient()
  const { data: { user } } = await supabase.auth.getUser()
  if (!user) return { error: 'Unauthorized', status: 401 }
  const roles = getStaffRoles(user)
  if (roles.length === 0 || !roles.some(r => allowed.includes(r))) {
    return { error: 'Forbidden', status: 403 }
  }
  return { user, staffRole: roles[0] }
}
```

**Compose, don't replace — RESEARCH.md's exact recommended shape** (new code, cites `requireStaffPage`):
```typescript
// lib/playbook/rooms.ts
import { requireStaffPage, type RequireStaffPageResult } from '@/lib/admin/gate'
import { createServiceClient } from '@/lib/supabase/server'

export async function requireRoomAccessPage(roomKey: string): Promise<RequireStaffPageResult> {
  const auth = await requireStaffPage() // base staff check, unchanged
  if (auth.staffRole === 'leadership') return auth // structural, never row-data (Pitfall 5)

  const service = createServiceClient()
  const { data: room } = await service.from('playbook_rooms').select('id').eq('key', roomKey).maybeSingle()
  if (!room) redirect('/admin/playbook')

  const { data: grant } = await service
    .from('playbook_room_role_grants')
    .select('role')
    .eq('room_id', room.id)
    .eq('role', auth.staffRole)
    .maybeSingle()
  if (!grant) redirect('/admin/playbook')

  return auth
}
```

**Rule to copy:** every Playbook room/sub-group/entry route AND page must independently call this — nav hide (Rail2) is UX only, never the authority (mirrors Phase 33's `requireStaffPage` self-guard discipline, Pitfall 6).

### `components/selects-player/useAudibleTimeAccumulator.ts` (hook, event-driven)

**Analog:** No direct prior hook exists — built against the live `<audio>` element already in `SelectsPlayer.tsx` (line ~938):
```typescript
<audio ref={audioRef} onEnded={() => setPlaying(false)} />
```

**Full recommended implementation (from RESEARCH.md Pattern 4 — copy near-verbatim):**
```typescript
export function useAudibleTimeAccumulator(
  audioRef: React.RefObject<HTMLAudioElement>,
  onFlush: (deltaSeconds: number, event: 'heartbeat' | 'pause' | 'ended' | 'unload') => void
) {
  const lastTimeRef = useRef<number | null>(null)
  const pendingRef = useRef(0)

  useEffect(() => {
    const el = audioRef.current
    if (!el) return

    function onTimeUpdate() {
      const t = el.currentTime
      if (lastTimeRef.current != null && !el.seeking) {
        const delta = t - lastTimeRef.current
        // Only small, forward, contiguous deltas count as audible playback.
        if (delta > 0 && delta <= 2) pendingRef.current += delta
      }
      lastTimeRef.current = t
    }
    function onSeeking() { lastTimeRef.current = null }
    function flush(event: 'heartbeat' | 'pause' | 'ended' | 'unload') {
      if (pendingRef.current > 0) { onFlush(pendingRef.current, event); pendingRef.current = 0 }
    }
    const heartbeat = setInterval(() => flush('heartbeat'), 10_000)
    el.addEventListener('timeupdate', onTimeUpdate)
    el.addEventListener('seeking', onSeeking)
    el.addEventListener('pause', () => flush('pause'))
    el.addEventListener('ended', () => flush('ended'))
    window.addEventListener('beforeunload', () => flush('unload'))

    return () => {
      clearInterval(heartbeat)
      el.removeEventListener('timeupdate', onTimeUpdate)
      el.removeEventListener('seeking', onSeeking)
    }
  }, [audioRef, onFlush])
}
```
**Critical:** extract the pure delta-accumulation logic (the `onTimeUpdate`/`onSeeking` math) into a separately-testable pure function — mirrors how `computeHealth()` is pure and independently tested from its RSC caller. Never a `setInterval`-based wall-clock timer (Pitfall 1 — this is the phase's explicit watch-out).

**Resolve + rate-limit + scope pattern** (lines 31-58):
```typescript
export async function POST(request: Request, { params }: { params: Promise<{ token: string }> }) {
  const { token } = await params
  const service = createServiceClient()

  const selects = await resolveSelectsByToken(service, token)
  if (!selects) {
    return NextResponse.json({ error: "This link isn't live." }, { status: 404 })
  }

  const ip = getClientIp(request)
  if (
    (await checkRateLimit(`selects-react:${token}:${ip}`, { maxAttempts: 60 })) ||
    (await checkRateLimit(`selects-react:${token}`, { maxAttempts: 300 }))
  ) {
    return NextResponse.json({ error: 'Too many reactions — please slow down.' }, { status: 429 })
  }

  const body = (await request.json().catch(() => null)) as Record<string, unknown> | null
  if (!body) return NextResponse.json({ error: 'Invalid request body' }, { status: 400 })
  const parsed = ReactBodySchema.safeParse(body)
  if (!parsed.success) {
    return NextResponse.json({ error: parsed.error.issues[0]?.message ?? 'Invalid request.' }, { status: 400 })
  }

  const track = await loadOwnSelectsTrack(service, selects.id, parsed.data.selectsTrackId)
  if (!track) return NextResponse.json({ error: 'Not found' }, { status: 404 })
  // ... attribution resolution below
}
```

**Never re-derive token resolution:** always call `resolveSelectsByToken` (`lib/selects/public-resolve.ts`) — never a second by-id lookup path (its module-header contract: "grep for share_token is this module's contract check").

CREATE OR REPLACE FUNCTION public.enforce_selects_reaction_cap()
RETURNS TRIGGER LANGUAGE plpgsql SECURITY DEFINER SET search_path = '' AS $$
DECLARE v_count INT;
BEGIN
  SELECT count(*) INTO v_count FROM public.selects_reactions
    WHERE selects_track_id = NEW.selects_track_id;
  IF v_count >= 500 THEN
    RAISE EXCEPTION 'selects reaction cap reached for track %', NEW.selects_track_id

  END IF;

END; $$;

**Source:** `lib/admin/staff-role.ts` — `StaffRole` union (`leadership | ae | bd | anr | it | legal | tms | accounting | marketing`), `getStaffRoles(user)` returns the full priority-sorted role set from `app_metadata.staff_roles`.
**Apply to:** The access-editor matrix's role columns; room-lead assignment (a NEW per-room layer, not a replacement of this set).

### Audit logging
**Source:** `lib/staff/audit.ts` — `logStaffAction(service, { actorId, action, targetType, targetId?, changes? })`
**Apply to:** every access-editor grant change, every Play publish, every SOP/Topic approve (D-31.2-01's explicit audit guardrail).
```typescript

  actorId: auth.user.id,
  action: 'approve_playbook_entry',
  targetType: 'playbook_entries',
  targetId: id,

```
Called UNCONDITIONALLY after every staff write, including idempotent no-ops. Never throws — never blocks the primary write on a log failure.

### Rate limiting (public/token-authed write routes)
**Source:** `lib/security/rate-limit.ts` — `checkRateLimit(key, { windowMs?, maxAttempts? })`, backed by the durable `check_rate_limit` RPC (migration 116). Fail-open on backend error.
**Apply to:** `/api/selects/[token]/engagement` heartbeat POSTs — reuse the exact per-(token+ip) and per-token dual-key pattern from `react/route.ts`.

### Public token resolution (Selects attribution)
**Source:** `lib/selects/public-resolve.ts` — `resolveSelectsByToken(service, token)`, `loadOwnSelectsTrack(service, selectsId, trackId)` (TOCTOU-safe scoping — never trust a bare id from the request body).

### Zod `.strict()` input validation
**Source:** `app/api/selects/[token]/react/route.ts`'s `ReactBodySchema`, and project-wide convention (`ContactCreateSchema`, `GamePlanTopicSchema`).
**Apply to:** every new POST/PATCH body — access-editor grant PATCH, entry create/approve, play/assignment create, engagement delta POST.

### Migration doctrine (zero-policy RLS + REVOKE, human-gated push)
**Source:** `supabase/migrations/128_ae_console_health.sql`, `129_health_rules_owner_defaults.sql`, `089_*` (staff_audit_log precedent).
**Apply to:** all new tables (`playbook_rooms`, `playbook_room_role_grants`, `playbook_room_leads`, `playbook_sub_groups`, `playbook_entries`, `plays`, `play_assignments`, `play_assignment_completions`, `selects_track_engagement`, `selects_opens`) — RLS enabled, zero policies, `REVOKE ALL FROM authenticated, anon`, service-role-only, never auto-pushed.
