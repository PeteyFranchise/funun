<objective>
Build the Playbook authoring API for the two content asset types (SOP checklists + coaching Topics), generalizing the live Tips `tip_draft`→`tip_approved` flow into a per-room `playbook_entries` draft→publish gate with server-derived approval authority. This is R9's core: leadership/ops author-and-publish; regular members draft-then-get-approved; edits apply forward-only.

Purpose: the authoring UI (plan 08) and the Game-Plan Topic merge (plan 08) both sit on top of these routes. Keeping the publish-gate authority server-derived (never trusting a client status) is the phase's explicit elevation-of-privilege defense.
Output: lib/playbook/entries.ts, the entries collection + item routes, + tests.
</objective>
