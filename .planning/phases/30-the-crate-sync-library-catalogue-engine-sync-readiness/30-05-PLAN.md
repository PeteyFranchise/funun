<objective>
Build the Sync Readiness worklist: the staff-facing backend that lists every incomplete track in the pipeline together with exactly which Sync Readiness items are unmet, so staff can guide artists to close the gaps.

Purpose: "Incomplete ≠ rejected" only works if there is a place that shepherds incomplete tracks to done. This is that engine's read half — a pure shaper plus a batched, staff-gated query.
Output: new `lib/sync-library/worklist.ts` (pure), new `app/api/sync-library/worklist/route.ts` (GET, staff-gated).
</objective>
