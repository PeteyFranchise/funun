# Plan 44.1-04: Security, cost, browser, and owner pilot gate

## Objective

Prove the managed-session beta is authorized, comprehensible, bounded, and affordable before broader
enablement.

## Verification

1. Two-account and block/removal tests across create/join/reconnect/token refresh; provider webhook and
   participant eviction verification; no token/secret leakage in logs/analytics/errors/URLs.
2. Chrome/Edge/Safari desktop, representative mobile viewing, device switching, permission denial,
   tab/background recovery, poor network, camera/mic loss, screen-share end, duplicate tabs, and idle end.
3. Run two-, four-, and six-person synthetic sessions; reconcile measured participant minutes, duration,
   transfer where applicable, and provider invoice/dashboard figures against Funūn usage records.
4. Verify feature flag, kill switch, participant/session cap, duration warning/hard end, global alert, and
   no auto-join/no recording/no transcription.
5. Owner and invited musician/producer UAT shares Logic/Pro Tools or representative DAW windows and rates
   text legibility, conversation audio, reference playback expectations, and room/chat continuity.

## Exit gate

Launch remains limited until measured cost/error thresholds, DPA/privacy sign-off, support runbook,
provider incident fallback, and owner UAT are recorded. Phase 44.2 is independent of broad video rollout
but requires this session lifecycle to be stable enough for integration.
