| Boundary | Description |
|----------|-------------|
| staff (AE/BD/leadership) → buyer_orgs write | all writes go through the service-role client behind requireStaff + isAssignedToOrg; no client-direct write path exists (migration 080 REVOKE) |
| request body → buyer_orgs update | only STAFF_EDITABLE_BUYER_ORG_FIELDS cross into the update |
| org id (path param) → scope check | an AE's access to an org id is decided by ae_user_id === caller, re-checked on read and write |
