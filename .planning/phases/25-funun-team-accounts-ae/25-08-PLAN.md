## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| member browser → theme cookie | ADMIN_THEME_COOKIE is a non-sensitive UI preference ('light'/'dark' only); it gates NO data or access |
| client toggle → server render | the toggle sets a cookie + a DOM attribute; the server re-reads the cookie next request — no privilege or data decision rides on it |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-25-13 | Tampering | ADMIN_THEME_COOKIE forged/arbitrary value | low | mitigate | readAdminTheme is a strict allowlist ('light' only, else 'dark') — an arbitrary value falls back to dark; no injection surface |
| T-25-14 | Information Disclosure | theme preference leaking role/identity | low | accept | The cookie carries only a UI preference; it is not tied to role, tenant, or PII |
| T-25-SC | Tampering | npm/pip installs | low | accept | No new dependencies — pure port of existing in-repo buyer-theme code |
</threat_model>
