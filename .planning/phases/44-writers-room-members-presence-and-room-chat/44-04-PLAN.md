# Plan 44-04: Creative-context bridges and phase verification

## Objective

Connect selected chat messages to durable creative context without collapsing chat into comments or Studio
Notes, then run the complete access and UX gate.

## Tasks

1. Implement approved **Convert to Studio Note** semantics as a new authorized note containing deliberate
   attribution/provenance and a source-message reference; never mutate the source message into a note.
2. Implement **Attach to section/take** as an explicit contextual link. Revalidate target and membership at
   write/read; a later deleted target renders a safe tombstone.
3. Add only low-noise system messages approved by the owner (for example a verified new take). Detailed
   repetitive changes remain in Diary.
4. Verify removal/block, retention, moderation, pagination, concurrent edits, reconnect, unread counts,
   notification failure, XSS, accessibility, mobile, and rights non-effects with two accounts.
5. Owner UAT confirms the Room members hierarchy, presence truthfulness, chat tone, note/comment boundaries,
   and wider-page interaction. Record migration state and exact verification results.

## Acceptance

- Conversion creates a separate durable record and preserves source provenance.
- System chat cannot become a noisy duplicate of Diary.
- Every rights/split/approval record is byte-for-byte unaffected by chat workflows.
- Phase is not complete without owner UAT and actual remote RLS checks after human migration application.
