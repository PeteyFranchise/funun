# Plan 44-03: Persistent chat rail, mobile drawer, and unread behavior

## Objective

Build the chat experience only after the owner applies/verifies the 44-02 migration.

## Tasks

1. Build a lazy-loaded desktop right rail and mobile focused drawer with grouped messages, sticky
   composer, timestamps, reply context, mentions, loading/history boundary, error/reconnect, and unread.
2. Keep the long Writer's Room independently scrollable; opening chat cannot cover the primary editor,
   strand keyboard focus, or reset unsaved lyric input.
3. Persist messages through 44-02 routes; use Realtime only as a hint then re-fetch authoritative rows.
   Do not rely on ephemeral broadcast/data-channel events as chat history.
4. Add muted/mention notification behavior approved in 44-02. Notifications carry a summary and room link,
   never message content or unreleased audio metadata.
5. Add empty/offline/retry/removed/member-left/blocked/edit/delete/moderation states and accessibility tests.

## Acceptance

- Refresh and reconnect reconstruct the same authorized conversation from the database.
- An unauthorized, blocked, or removed account receives no message existence/content oracle.
- Chat remains usable during room scrolling on desktop and in a dedicated mobile surface.
- Focused tests, strict typecheck, and manual narrow/desktop UAT pass.
