# Plan 42-04: Settings cleanup, redirects, and release verification

## Objective

tab removal that leaves operational entry points inconsistent.

## Tasks

1. Reduce `SETTINGS_TABS` to Rights & identity, Public profile, and Payouts; update Settings heading/copy
   and its tab-coverage tests.
2. Replace the three old Settings pages with server redirects to filtered `/requests` views. Preserve a
   valid record ID/filter when present; never echo unvalidated query data.
3. Audit all links/copy/tests for `/settings/permissions`, `/settings/rights-proposals`,
   `/settings/master-claims`, “Rights proposals,” and Settings-based decision instructions.
4. Preserve work/Song Passport links to master-claim history and workspace links that initiate requests.
5. Run full focused suite, lint/typecheck/build as supported, and manual UAT for three request types on
