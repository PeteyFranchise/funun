## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-23-22 | Elevation of Privilege | anon visitor submitting a License request | high | mitigate | isPublic engagement gate opens the modal instead of setModalId; server route still re-authorizes (defense in depth) |
| T-23-23 | Information Disclosure | login error revealing account existence | medium | mitigate | Show a generic invalid-credentials message; register confirmation is non-revealing (23-04) |
| T-23-24 | Tampering | client bypassing register validation | low | mitigate | buildRegisterPayload runs client-side for UX; the server route re-validates authoritatively (23-04) |
| T-23-25 | Spoofing | open redirect after login | medium | mitigate | Navigate via postSignInPath (same-origin safeNext guard) — never a raw client-supplied URL |
</threat_model>
