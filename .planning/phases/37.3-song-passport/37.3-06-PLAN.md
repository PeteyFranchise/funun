# Phase 37.3 Slice 6 — Artifacts, Portability and Custody

## Objective

Generate controlled, traceable outputs from immutable Song Passport snapshots and preserve a
human-readable custody history when a master is delivered, transferred or sold.

## Scope

- Build canonical snapshot hashing and provider-neutral JSON/sidecar manifests.
- Generate tagged MP3 delivery copies when an MP3 source is eligible; use sidecars otherwise.
- Filter private fields according to grant and delivery purpose.
- Add append-only custody events, export receipts and controller history.
- Provide a portable custody package and retention/deletion request workflow.

## Verification

- Same snapshot produces the same canonical hash.
- Artifacts contain only fields approved for their audience and purpose.
- Every receipt resolves to a snapshot and exact source recording.
- Ownership/controller changes preserve before/after parties and prior receipts.
