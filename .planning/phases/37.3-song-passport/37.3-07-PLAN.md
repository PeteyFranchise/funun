# Phase 37.3 Slice 7 — Pilot, Operations and Claims

## Objective

Roll Song Passport out to a controlled cohort with actionable health signals, a support playbook
and public language limited to verified capabilities.

## Scope

- Add per-account/per-work cohort controls in addition to the environment kill switch.
- Add operational metrics for discovery, conflicts, approvals, graduation, exports and failures.
- Add a support SOP and revise the Playbook doctrine with shipped operating procedures.
- Define the pilot acceptance matrix and evidence-scoped claim ladder.
- Document rollback, escalation and incident handling.

## Verification

- Non-cohort users see no Passport when global rollout is disabled.
- Support can trace each material action without viewing unauthorized private field values.
- Pilot fixtures cover solo, multi-writer and legacy/released work stories.
- Claims distinguish current export capability from future standards/partner delivery.
