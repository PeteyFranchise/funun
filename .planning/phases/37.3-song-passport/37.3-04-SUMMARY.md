# Phase 37.3 Slice 4 — Summary

## Built

- Migration 153 adds expected-head, row-locked revision writes so concurrent proposals produce a visible conflict instead of a silent overwrite.
- Identity subjects can confirm only their own identity facts.
- Explicit grants control composition/release approval, master selection, exports, clean-master copies and custody actions.
- Approvals freeze canonical, SHA-256-addressed snapshots and record the authority action.
- Disputes create review tasks and notifications; post-approval proposals create successor review tasks. Task completion alone never changes trust/readiness.

## User effect

Collaborators can propose and disagree safely. A previous value and approved snapshot remain recoverable, and legal/release authority never arrives from Writer's Room membership alone.
