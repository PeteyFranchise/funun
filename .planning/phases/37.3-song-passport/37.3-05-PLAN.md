# Phase 37.3 Slice 5 — Masters and Release Report Graduation

## Objective

Identify the exact recording version approved as a master and carry an approved snapshot into
the Release Report without retyping or conflating composition and recording truth.

## Scope

- Add append-only recording lineage and master-designation records.
- Support explicit successor-master designation while preserving former masters.
- Support a final mix uploaded in or outside the Writer's Room.
- Map approved Passport facts into a linked release/track through an explicit review action.
- Preserve the existing manual Release Report flow as a safe fallback.

## Verification

- Three-version lineage and successor-master stories pass.
- A master always resolves to an exact file/version and snapshot.
- Graduation is idempotent and never silently overwrites an existing release fact.
- Composition facts remain shared while recording facts remain version-specific.
