# Phase 37.3 Slice 4 — Trust and Approval Workflows

## Objective

Allow collaborators to propose and confirm facts according to explicit authority while
preserving prior revisions and making disagreements visible.

## Scope

- Add proposal, own-identity confirmation, dispute, conflict resolution and approval actions.
- Create immutable approval snapshots for composition and release scopes.
- Add review-task state and notification hooks without letting task completion alter readiness.
- Re-check work membership, role, grant, target subject and field privacy on every write.
- Make post-approval material changes create a successor review rather than mutate approval.

## Verification

- Authorization matrix and cross-subject identity tests pass.
- Two proposals are preserved and surfaced as a conflict.
- Confirmation never rewrites an earlier value.
- Approved snapshots cannot be updated or deleted.
- Completing a task alone does not change a fact's trust state.
