# Phase 37.3 Slice 3 — Sound Vault Interface

## Objective

Place a recognizable, feature-gated Song Passport inside each Sound Vault work without
rearranging the Writer's Room.

## Scope

- Add a four-layer Passport panel for identity, composition, recording and release facts.
- Display source, trust state, privacy, conflicts and missing-data explanations.
- Display review tasks and readiness as a consequence of trusted facts, not task completion.
- Keep all server data loading behind the Song Passport feature/cohort gate.
- Preserve the existing Writer's Room layout and controls.

## Verification

- Disabled gate changes no existing page path or visible layout.
- Authorized members see only privacy-scoped data.
- Each field makes its layer, state and source understandable in plain language.
- Empty, loading, conflict, error and populated states render safely.
