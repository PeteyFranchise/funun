and keep it in sync when the prop changes. Derive
`const drawnPeaks = isValidPeaksPayload(livePeaks) ? livePeaks : null`. A payload that fails the

Replace the bar row's data source. When `drawnPeaks` is non-null, map over it instead of the

for this surface, so the hairline collapses rather than the take.

removing the id on unmount only if the request never resolved.

Render `waveformError` as the UI contract's copy — that the take's waveform could not be read and

that state is expected and self-healing.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| signed storage URL → browser decode | The backfill fetches a take's private object and decodes it client-side |
| browser → `PATCH /versions/[versionId]` | The healed waveform is written back by whoever opened the take |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-39-18 | Denial of Service | backfill retry storm | high | mitigate | A module-level in-flight set keyed by version id admits one decode per version per page, and a failure is not retried within the mount — the next page load is the next attempt. Without this, a take whose object is unreadable would decode on every render of every mounted player |
| T-39-19 | Spoofing | a corrupt or hostile peaks array rendered as a waveform | medium | mitigate | `isValidPeaksPayload` gates the draw with the same rule the route enforces; anything failing it renders the rest state rather than a partial or distorted shape |
| T-39-20 | Repudiation | a fabricated waveform implying content that is not in the audio | high | mitigate | The hardcoded array is deleted outright and a grep gate asserts zero occurrences; the pending state is flat, uniform and pulsing, with no progress fill, so it cannot be mistaken for data |
| T-39-21 | Information Disclosure | signed playback URL reuse | low | accept | The backfill fetches the same signed URL the `<audio>` element is already bound to, from the same session, with the same lifetime — no new exposure. The identical pattern ships today in `analyzePlaybackLevels` |
| T-39-SC | Tampering | npm/pip/cargo installs | high | mitigate | No package is added. `animate-pulse` is an existing Tailwind utility and the decode path is a browser built-in |
</threat_model>
