<objective>
Close the phase where no automated test can reach. Three things in this phase are only true if a
human confirms them: the migration is actually applied, a second person genuinely cannot see
another writer's pins, and slowing a sung take genuinely leaves it in key.

Purpose: the pins table's whole design is one row-level-security policy. Jest cannot impersonate
two authenticated Postgres roles, so the only real proof of D-11 is two accounts and a real
database — the same discipline Phase 38's permission branch required. And the felt qualities this
phase exists to deliver, a waveform that appears instantly and a 0.5x playback that is still
judgeable, are not assertable by construction.

Output: an applied migration with list parity, and a recorded outcome for each of the five
manual verifications.
</objective>

opens at 1x with the 1x step highlighted.
