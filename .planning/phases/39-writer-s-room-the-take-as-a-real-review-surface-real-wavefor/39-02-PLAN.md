Export `PEAKS_BAR_COUNT = 200` and `REST_BAR_HEIGHT_PERCENT = 15`.

Export `scalePeaksToPercent(peaks: number[]): number[]` — maps each normalized 0..1 peak to
`Math.round(peak * 100)` and clamps the result into 0..100, dropping any non-finite value to 0.

Export `isValidPeaksPayload(value: unknown): value is number[]` — true only when `value` is an
array whose length equals `PEAKS_BAR_COUNT` and every element is an integer in 0..100. This is the
single shared rule; plan 39-03's route schema and both players call it rather than re-stating the
bounds. Keep it dependency-free so a Next.js route handler can import it.

Export `levelMatchedPeaks(peaks: number[], volume: number): number[]` — scales each bar by
`volume`, rounds, clamps into 0..100 and floors at 1 so a quiet side still draws a visible strip.
A `volume` of 1, or a non-finite volume, returns the input unchanged. This is D-02's mechanism:
the A/B panel draws what its level-matched playback actually sounds like.

Export `async function extractPeaksFromBuffer(buffer: Pick<AudioBuffer, 'length' |
'numberOfChannels' | 'getChannelData'>, barCount = PEAKS_BAR_COUNT): Promise<number[]>` — or a
synchronous equivalent if no await is needed; prefer synchronous and name it
`peaksFromBuffer`. It calls the imported `waveformPeaks(buffer, barCount)` and returns
`scalePeaksToPercent` of the result. This is the hum / record-over path, where the browser
already holds a decoded buffer and must not decode a second time.

Export `async function extractPeaksFromBlob(blob: Blob, barCount = PEAKS_BAR_COUNT):
Promise<number[]>` — opens one `AudioContext`, `decodeAudioData(await blob.arrayBuffer())`, hands
the buffer to `peaksFromBuffer`, and closes the context in a `finally` exactly as
`analyzePlaybackLevels` does. Throw a descriptive Error ("Could not read this take's waveform.")
on a decode failure so the caller can fall back to the rest state.

Export `async function extractPeaksFromUrl(url: string, barCount = PEAKS_BAR_COUNT):
Promise<number[]>` — fetches a signed playback URL, throws a descriptive Error on a non-ok
response, and delegates to the same decode path. This is D-03's lazy backfill entry point.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| untrusted audio bytes → `decodeAudioData` | A take's stored object is decoded in the viewer's browser |
| client payload → shared validator | `isValidPeaksPayload` is imported by a Next.js route handler and must therefore stay free of browser globals |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-39-03 | Denial of Service | peaks payload shape | medium | mitigate | `isValidPeaksPayload` fixes cardinality at `PEAKS_BAR_COUNT` and per-value range at 0..100 in one place; plan 39-03's route schema imports it rather than restating the bounds, so the two can never drift |
