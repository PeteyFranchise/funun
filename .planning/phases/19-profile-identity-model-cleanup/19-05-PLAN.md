## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client (Settings form) -> PATCH /api/profile | Untrusted body carries rights field edits + the confirm_prefill_fields signal; the server must own the confirm state and never accept a client-supplied claim_prefill blob. |
| browser -> artist_profiles.claim_prefill | The unconfirmed flag must not be forgeable to launder a stranger's typo as an owned/confirmed value. |
