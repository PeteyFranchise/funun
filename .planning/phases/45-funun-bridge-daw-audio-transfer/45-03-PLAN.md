# Plan 45-03: Desktop companion core and managed Funūn Drop

## Objective

Build the approved first-platform Bridge client with secure sign-in, room mapping, crash-safe local spool,
and resumable upload—without auto-sending ambiguous/incomplete bounces.

## Tasks

1. Scaffold the chosen signed/updatable desktop runtime with separate production/test environments,
   keychain credential storage, secure deep-link/callback handling, CSP/network allowlist, and no secrets
   in the public repository or crash reports.
2. Create a managed Funūn Drop and local job database/spool. Detect file stability/close semantics; reject
   symlink/path escape, package/directory, unsupported type, zero/truncated/actively-growing files.
3. Inspect audio locally for approved facts and checksum without blocking UI. Show target room, take label,
   format, duration, sample rate, bit depth, channels, size, and warnings before send.
4. Map a DAW project/folder to one default room with visible mapping and revoke response. Cross-room target
   always requires the approved extra confirmation.
5. Upload through 45-02 TUS with pause/resume/retry/progress/cancel, sleep/restart/network-loss recovery,
   idempotent completion, and server-verified success before optional local cleanup.
6. Add safe update, sign-out, revoke-device, clear-local-cache, diagnostic export with redaction, and
   accessibility. Never log local paths/titles/audio facts remotely without explicit redacted support flow.

## Acceptance

- Killing/restarting Bridge or losing network cannot corrupt/duplicate a take.
- No file is deleted before verified durable completion.
- Revoked/removed access stops queued/new transfers safely and preserves a local recoverable source.
- Signed/notarized build, updater, installer/uninstaller, and synthetic security/UAT pass on first OS.
