<objective>
Make a linked split sheet and its Sound Vault project a single source of truth for who wrote what:
writers/roles/splits stay in sync WHILE the sheet is a living draft, in both directions, and the link
snaps the moment the sheet is sent for signature (migration 062 freeze) — after which the project keeps
evolving independently and splits move only through the sheet's approve/counter flow.

Purpose: Deliver "no data re-entry" for the writer roster without opening a new money-mutation path.
Hook the EXISTING PATCH choke point (partiesActuallyChanged + assertEditable) and reuse the composer
write-back machinery rather than building a parallel sync engine (RESEARCH Don't-Hand-Roll). Key the
sync-active window off lifecycle.ts's own freeze vocabulary, not a literal `=== 'draft'` check
(RESEARCH Pitfall 5). Implements the `sheet-project-sync` decision and reinforces ① (splits negotiated
only via the sheet flow).

Output: a pure `lib/split-sheets/project-sync.ts` mapping/conflict module, an `isSyncActive` predicate
on lifecycle.ts, and forward + reverse sync hooks on the two existing choke-point routes.
</objective>

<planner_decisions>
## Planner decisions

- **Live-sync indicator = refresh-on-load, not Realtime (RESEARCH Open Q3 recommendation):** this
  phase does not add a Realtime channel for the sync indicator — the split-sheet detail / vault
  surfaces already reflect state on page load, matching the Contract Locker precedent. Revisit only if
  UAT surfaces staleness complaints.
- **Bidirectional is in scope (locked `sheet-project-sync` decision):** both forward (sheet→project)
  and reverse (project→sheet) are shipped; neither is deferred. Reverse sync is deliberately scoped to
  the single-account (editor == initiator) case to honor ①'s "no silent cross-account split edits."
- **No parallel sync engine:** both directions hook the existing PATCH choke points and reuse the
  existing composer write-back / party-write shapes — no second diff/freeze mechanism (RESEARCH
  Don't-Hand-Roll).
</planner_decisions>
