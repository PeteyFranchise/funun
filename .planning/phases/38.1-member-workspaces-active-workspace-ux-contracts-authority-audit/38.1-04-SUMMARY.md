# Phase 38.1-04 Summary — Workspace Contract Locker Shelf

## Delivered

- Added a Contract Locker destination to persistent workspace navigation.
- Added a workspace-local shelf grouped by Member and then by project context, with document type
  visible on each record.
- Added expandable provenance details covering declared scope, uploader, upload time, Member
  confirmation, effective date, expiry, supersession, document status, and whether Funūn witnessed
  the signature in its own signing flow.
- Added distinct neutral states for awaiting confirmation, confirmed record, upcoming effective date,
  expired record, superseded record, missing document link, and malformed record data.
- Added links to canonical personal/project document surfaces only when the authenticated session can
  already read the underlying document through personal or project RLS.
- Added loading, empty, failure, bounded-result, private-document, expired, and superseded experiences.
- Kept counsel-gated wording explicitly provisional and separated system document status from legal
  interpretation.

## Security boundaries

- Agreement evidence is read first through the authenticated
  `workspace_agreement_evidence_select` RLS policy. The service client is not an evidence visibility
  authority.
- Direct document reads select only `id`, `project_id`, `track_id`, `type`, `status`, and `signed_at`.
- Workspace document reads use migration 193's `workspace_read_documents` function, preserving its
  caller binding and live six-hop permission check.
- The service client may locate `project_id` only for document ids already returned by evidence RLS;
  that locator output is never presented and must pass the authenticated document reader before any
  document metadata appears.
- File URLs, storage paths, document bodies, signer identities, verification checks/summaries, and
  signed URLs are neither selected nor returned.
- Private or otherwise unreadable documents remain a neutral “Member-controlled document” record
  with no inferred type, project, status, or canonical link.
