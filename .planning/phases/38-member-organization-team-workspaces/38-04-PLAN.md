## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| workspace → a Member it has merely named | The proposal row exists in the workspace's context but points at a stranger's account |
| stored evidence → authority-tier permission issuance | An expired, superseded or scope-less document must not keep unlocking consequential powers |
| workspace → the Member's refusal record | A workspace learning who blocked it enables retaliation and targeted re-approach |
