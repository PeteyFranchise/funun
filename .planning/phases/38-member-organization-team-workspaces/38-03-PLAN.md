## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| authenticated client → workspace tables | PostgREST exposes every table by default; the lockdown is what makes these service-write-only |
| workspace policy → workspaces/members tables | Two tables whose visibility rules each need to read the other — the documented 42P17 recursion class |
| service role → audit log | The one writer; the log must be unalterable even by the code that wrote it |
