<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client (buyer) → PostgREST | A buyer could hit the tables directly; RLS + column GRANTs must fail closed |
| public token viewer → selects | The unauthenticated player reaches selects only via the unguessable share_token (service-role read) |
| staff (AE) → other AE's data | Cross-AE reads must be impossible at the data layer, not just the UI |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-31-02 | Information Disclosure | selects buyer-read arm | high | mitigate | Buyer SELECT policy limited to status IN sent/approved/changes_requested scoped by is_buyer_org_member; drafts never buyer-visible; destructive grants REVOKEd. |
| T-31-03 | Spoofing | selects.share_token | high | mitigate | UNIQUE gen_random_bytes(16) token — no sequential/guessable id; the token is the sole authorization for the public route. |
| T-31-04 | Information Disclosure | buyer_org_contacts / client_relationship_log / ae_user_id | high | mitigate | Staff-only zero-policy + full REVOKE from authenticated/anon; buyer_orgs.website + ae_user_id never added to an authenticated GRANT. |
| T-31-05 | Information Disclosure | selects_tracks.track_id | medium | accept | FK to tracks(id) enables read-time rights-ready re-eval (31-04); a deleted track cascades, degrading loudly rather than dangling. |
| T-31-SC | Tampering | package installs | high | accept | No new packages in this plan (SQL + Jest text-tests only). |
</threat_model>
