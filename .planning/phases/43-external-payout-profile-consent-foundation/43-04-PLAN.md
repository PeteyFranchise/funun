# Plan 43-04: Security verification and foundation release gate

## Objective

Prove the private foundation is safe enough for Phase 43.1 to consume; do not yet disclose data to any
external payer.

## Verification

1. Run migration structural tests and owner-run post-apply production probes only after the owner applies
   and records the migration. Verify actual grants/RLS, not only SQL text.
2. Run two-account and role-matrix tests, IDOR/tampering tests, CSRF and step-up expiry tests, payload-size
   bounds, concurrency/version tests, and deletion/retention tests.
3. Capture logs, errors, analytics, notifications, audit rows, request URLs, browser storage, and network
   bodies during representative flows; scan for seeded canary secrets.
4. Exercise key rotation, unavailable KMS, corrupted ciphertext, restore from backup, deletion request,
   and support escalation runbooks.
5. Conduct owner UAT with synthetic values only. Obtain security/legal sign-off on notices and scope.

## Exit gate

Phase 43.1 stays blocked unless all tests pass, the production migration is actually recorded as applied,
the key service is operational, and runbook owners are named. A schema or UI existing is not completion.
