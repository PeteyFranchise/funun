Wire Sentry (D-01 locked vendor) into the Next.js 15 App Router for privacy-scrubbed server + browser error/trace monitoring with release + source-map correlation (R5). Purpose: server/browser exception aggregation with regression alerting, affected-user counts, and request correlation — the core R5 capability Funūn cannot hand-roll. Depends on Plan 02's scrub module for `beforeSend`.

</objective>
