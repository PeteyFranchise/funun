<objective>
Build the repeatable, non-production k6 (D-12 locked tool) load & capacity harness (R7) that finds Funūn's real constraint rather than asserting a marketing concurrency number. Scripts live under `scripts/load/` (dev-only, never bundled, never in `package.json`), ramp 25 → 500 concurrent VUs across the high-traffic routes found by code inspection, enforce mid-run `abortOnFail` stop conditions, and emit a capacity report table across all five ramp levels. A target guard rejects a production hostname by construction (D-11). The harness runs against a Vercel Preview deploy pointed at a separate staging Supabase project.

Purpose: R7 is dev-only tooling with no runtime coupling; it produces the measured baseline that Plan 08's baseline-adjusted thresholds and Plan 10's monthly capacity report cite. Depends on Plan 03 (/api/health to poll) plus owner-created staging env + k6 install.
Output: `scripts/load/*` k6 scenarios + ramp orchestrator + target guard + README, and `docs/observability/CAPACITY-REPORT.md`.
</objective>
