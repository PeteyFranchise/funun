<objective>
Build the two shared observability primitives that every other privacy-sensitive surface depends on: (1) `lib/observability/scrub.ts` — a pure, Unicode-safe PII/secret scrubber reused by Sentry's `beforeSend` (R5), and (2) `lib/logging/correlation.ts` + `lib/logging/logger.ts` — the minimal correlation-ID + structured-logging convention (R6) that standardizes the repo's ad-hoc `requestId` usage without a pino/winston footprint.

Purpose: land the leaf utilities first (no dependencies) so Wave 2's Sentry wiring and the daily cron consume tested, secret-safe building blocks. The strongest guarantee for R6 is structural — the logger emits an explicit safe-field allowlist and never accepts a raw record, so it cannot leak what it never receives; scrub.ts (R5) is the defense for the SDK path where arbitrary exception payloads DO arrive.
Output: scrub + correlation + logger modules and their Jest tests.
</objective>
