<objective>
Build the production-safe read-only health endpoint `GET /api/health` (R4): a liveness confirmation plus exactly one inexpensive, strictly-timeout-bounded, read-only Supabase check that returns a minimal `healthy`/`degraded` body, never writes, never throws, and never leaks secrets/schema/env/tokens/exception text. It is the cheap authoritative surface Better Stack (Plan 07) and the daily cron (Plan 05) poll.

Purpose: the health route is a foundational Wave-1 artifact with no dependencies; landing it first unblocks the external uptime monitor and the load harness (which polls it). Because `middleware.ts`'s matcher excludes `/api`, this route's own code is the entire security boundary — it must self-guard against being a DB-amplification vector.
Output: `app/api/health/route.ts` + `route.test.ts` covering healthy / degraded / timeout / secret-redaction.
</objective>
