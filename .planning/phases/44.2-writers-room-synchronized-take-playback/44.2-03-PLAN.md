# Plan 44.2-03: Cross-network verification and owner listening UAT

## Objective

Verify useful collaborative listening across real network/browser conditions without false precision claims.

## Verification

1. Test two-to-six participants across mixed Chrome/Safari/Edge, Wi-Fi/mobile latency, packet loss,
   background/foreground, reconnect, host transfer, device audio changes, and simultaneous chat.
2. Record start skew, steady-state drift, correction count/audibility, buffering, failed listener isolation,
   and egress. Establish honest beta thresholds and copy for degraded/out-of-sync states.
3. Attempt IDOR and forged control events; remove/block a participant and revoke selected-take access
   during playback; prove both control and audio stop appropriately.
4. Inspect provider traffic/storage to prove no take/master audio was published into the call.
5. Owner/producer UAT compares synchronized stored-take playback with DAW screen-share audio and confirms
   the UI clearly distinguishes durable take from reference call audio.

## Exit gate

Ship only if the measured experience is musically useful for shared review and the UI never implies
sample-accurate DAW synchronization. Otherwise retain local playback and defer this feature.
